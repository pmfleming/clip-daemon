## Stage 1 — move already owned publication bytes

`selected_bytes` used the bounded file-reading helper on an owned byte vector,
allocating and copying the whole payload again. It now reuses the same size
validator and moves the buffer, retaining configured/hard limits and error text,
stored-length checks, stale revision checks and captured MIME authority.
The existing local-image action test also checks rejection below payload size.

Validation/results are recorded with each stage below.

Stage 1: `cargo test --locked --all-features --lib history::mutation::tests`
(2 passed) and `... --lib selection::tests` (1 passed); rustfmt and diff checks
pass. Post-initial `rqlens measure hotspots` succeeds (`stage-1-hotspots.json`).

## Ranked next five, selected after stage 1

1. Read/validate annotation output once and commit those exact bytes: the old
   path read once for full PNG validation and reopened for commit, allowing the
   second read to differ. Preserve PNG/size/dimension/regular-file guards.
2. Reuse resolved content inside storage insert/replace: both resolved twice,
   including file URI parsing, metadata and image header I/O. `write_content`
   remains a hotspot (cognitive 13, cyclomatic 24, Halstead effort 76,430.72).
   Identity/ownership must still be checked at the echo decision.
3. Share sidecar validation: startup repeats the commit/shutdown owner checks;
   `Database::open` is the largest production hotspot (cognitive 21, cyclomatic
   53, effort 155,123.84). Keep nofollow/type/link/owner checks and reject dangling
   sidecar symlinks as consistently as ordinary symlinks.
4. Preflight file-publication size before constructing a second full URI payload:
   currently allocates/copies even for rejected input. Reuse the size validator
   and preserve exact copy/cut wire bytes and error semantics.
5. Isolate owner-admission process evidence from socket-slot saturation: the
   baseline and isolated repeat fail at line 980, immediately after audit-based
   cancellation observation. Cancellation is not a connection-slot-release
   acknowledgement. Preserve the 64-operation global limit and all peer/receipt
   assertions; socket connection bounds belong to shared transport tests.

The larger privacy/Wayland state machines were left intact: extracting wrappers
would shift metrics without removing work. Bounded preview/trigram rewrites are
lower priority than these verified copy, validation and duplicated-I/O paths.

## Stage 2 — commit the validated annotation buffer

`read_edited_image` returns the exact fully decoded PNG bytes; annotation commits
that buffer and screenshot publication uses it too. It retains regular-file,
configured/hard byte, PNG-only, dimensions
and full-decode guards. The existing five-format/size cases, symlink and truncated
PNG checks remain; successful validation now also proves the buffer survives a
subsequent file replacement. This closes the second-read gap, not all possible
filesystem races between metadata and the initial open.

Stage 2: `cargo test --locked --all-features --lib history::` passes 16 tests,
including image formats/limits, screenshot commands, operation cancellation and
partial publication. Rustfmt/diff checks pass. The first compile identified the
remaining screenshot caller; it was migrated to the same validated-buffer owner.
