   Edit ownership/publication/single-use cases share one matrix; MIME priority
   cases use the existing fixture runner; delayed-paste tests share task setup.
   Added expiry, configured/hard edit limits, non-consuming invalid paste,
   Unicode/short/punctuation/repeated/bounded trigrams, active+pending admission,
